第一章已经讲过[矩阵乘法与线性层]({{< relref "/posts/matrix-multiplication-and-linear-layers" >}})。这次不重新推导矩阵运算，而是理解：**一个输出单元怎样组合输入，以及反向时贡献怎样汇总。**

## 1. 一个输出单元，就是一种加权组合

假设用面积、卧室数描述一套房子：

```text
输入 x = [50,2]
权重 w = [0.1,3]
偏置 b = 1

z = 0.1×面积 + 3×卧室数 + 1
  = 0.1×50 + 3×2 + 1
  = 12
```

```text
面积 50 ──乘 0.1──┐
                  ├──相加，再加偏置 1──→ 输出 12
卧室数 2 ──乘 3───┘
```

这个单元接收两个特征，输出一个数。权重决定怎样组合，偏置提供与当前输入无关的加项。

**12 不一定就是预测房价。** 在隐藏层中，它可以是供后续层使用的一个新特征，其含义由任务与训练塑造。

权重还决定输入变化的影响：面积不变，卧室数增加 1，输出增加 3。一般地：

```text
Δz = 0.1×Δ面积 + 3×Δ卧室数
```

权重固定时，这是精确关系，不只是局部近似。输出对两个输入的偏导数分别为 0.1、3。只把偏置从 1 改为 10，输出增加 9，这两个偏导数不变。

不过不能说卧室数“重要 30 倍”，因为两种输入的单位不同；面积换单位，对应权重也会变。

## 2. 多个输出单元，并列地看完整输入

加入第二个单元：

```text
z₁ = 0.1×面积 + 3×卧室数 + 1
z₂ = 0.2×面积 − 卧室数

[50,2] → [12,8]
```

两个单元都有自己的权重、偏置，都看完整输入，不是一个只看面积、另一个只看卧室数。它们并列计算不同组合，不是依次处理。

在 PyTorch 的权重存放约定下：

```text
W = [[0.1, 3],
     [0.2,−1]]
b = [1,0]

z = x @ Wᵀ + b
```

W 每一行对应一个输出单元。Linear(2,3) 的 weight.shape 为 (3,2)，bias.shape 为 (3,)，一共有 6+3=9 个参数。

输入 8 套房子，shape 为 (8,2)，输出就是 (8,3)。改成 100 套也不增加参数：**所有样本共用相同的三个单元。** 输出单元数决定输出特征数，不决定样本数。

## 3. 一个单元反向时，分别给谁传什么？

先看单输出：

```text
z = w₁x₁ + w₂x₂ + b
```

假设后续最终得到标量损失 L，传到这里的上游导数为 ∂L/∂z=2。当前 x=[50,2]、w=[0.1,3]：

| 对谁求导 | 链式法则 | 结果 |
| --- | --- | ---: |
| w₁ | 2×x₁ | 100 |
| w₂ | 2×x₂ | 4 |
| b | 2×1 | 2 |
| x₁ | 2×w₁ | 0.2 |
| x₂ | 2×w₂ | 6 |

**输入值决定权重梯度，权重值决定传给输入的梯度。** 若 x 来自上一层，输入梯度就继续向前传播；若 x 是不需要梯度的原始数据，可以不为它求导，w、b 仍正常得到梯度。

一个容易忽略的前提：保持输入和上游导数不变，单改 w₁，它自己的本次梯度仍为 2×50；传给 x₁ 的梯度 2w₁ 则会变。完整网络中，上游导数也可能随前向结果变化，不能无条件推广“权重变化不影响自身梯度”。

## 4. 多个输出，共享输入的梯度要相加

回到两个单元，假设上游导数为：

```text
∂L/∂z₁ = 2
∂L/∂z₂ = 3
```

x₁ 同时影响两个输出，贡献要汇总：

```text
∂L/∂x₁ = 2×0.1 + 3×0.2 = 0.8
∂L/∂x₂ = 2×3 + 3×(−1) = 3
```

```text
z₁ 传给 x₁：2×0.1 ──┐
                      ├──相加──→ 0.8
z₂ 传给 x₁：3×0.2 ──┘
```

若 z₂ 的上游导数改为 0，则传给 x₁ 的梯度是 `2×0.1=0.2`，**不是 2**。2 只是到达 z₁ 的导数，还要乘局部权重，才是对 x₁ 的贡献。

这就是计算图的规则：同一输入经多条路径影响 L，各路径贡献相加。

## 5. 多条样本，共享权重的梯度也要相加

不同样本使用同一个 w₁，因此每条样本都会给它贡献梯度。仍以单输出单元为例：

| 样本 | 输入 | 最终 L 对该样本输出的上游导数 |
| --- | --- | ---: |
| A | [50,2] | 2 |
| B | [100,3] | −1 |

```text
∂L/∂w₁ = 2×50 + (−1)×100 = 0
∂L/∂w₂ = 2×2  + (−1)×3   = 1
∂L/∂b  = 2 + (−1)        = 1
```

w₁ 总梯度为零，不代表每条样本没有影响，也可能是贡献抵消。若 B 的上游导数改为 0，w₁ 的梯度就为 100。

所以有两个汇总位置：**多个输出在共享输入处汇总，多条样本在共享权重处汇总。**

## 6. Batch 越大，梯度就一定越大吗？

不一定，还要看损失怎样汇总。若各样本损失为 ℓᵢ，使用平均损失：

```text
L = (ℓ₁+…+ℓB)/B
∂L/∂w = (∂ℓ₁/∂w+…+∂ℓB/∂w)/B
```

Linear 的规则仍是相加，但**上游导数已经带上 1/B**，不能再重复除一次。

例如两条样本各自损失对 w 的梯度为 100、−100：只看 A，平均梯度是 100；A、B 一起为 0；把 A、B 完整重复一遍，平均梯度仍是 0。

换入不同样本，平均梯度可能变化；在当前逐样本计算再平均的模型里，把同一批完整重复，平均梯度不变。若使用求和损失，完整重复才会让梯度翻倍。若每条样本的梯度都是 10，100 条的平均梯度仍是 10。

前一节表中的 2、−1 已经是最终 L 的上游导数。改变 batch 后，不能默认这些数保持不变，需要重新按损失计算。

### 平均在哪里指定？

每条样本一个预测值时，可以明确写：

```python
pred = torch.tensor([110., 210.], requires_grad=True)
target = torch.tensor([150., 250.])

per_sample_loss = (pred - target) ** 2  # [1600,1600]
loss = per_sample_loss.mean()          # 1600
loss.backward()
```

mean 也是计算图中的运算，反向给各条损失传回 1/2，再经过平方误差、Linear。**不需要 backward 后再把参数梯度除以 2。**

也可使用 `torch.nn.MSELoss(reduction="mean")`：

| reduction | 含义 |
| --- | --- |
| none | 保留各元素损失 |
| sum | 所有元素求和 |
| mean | 所有元素取平均 |

MSELoss 的 mean 面向所有元素；当前每条一个输出，才同时是样本平均。每条多个输出时，还会平均输出维度。

## 7. 一个输出保留的，只是一种组合

同一个单元可能无法区分不同输入：

```text
z₁ = 0.1×面积 + 3×卧室数 + 1

[50,2] → 12
[80,1] → 12
```

面积增加 30、卧室数减少 1，两份变化抵消。单凭这个输出，无法区分这两个输入。

第二个单元 `z₂=0.2×面积−卧室数` 则分别输出 8、15，可以区分它们。多个单元能保留不同组合，但不保证信息不重复：权重、偏置完全相同的单元，输出也完全相同。

因此，不能仅凭系数给隐藏单元强行命名“大小”“舒适度”等含义。先看它计算了哪种组合，再看训练后它在网络中的作用。

## 小结与自检

Linear 的核心是**并列组合输入、跨样本共享参数、反向汇总路径贡献**。它怎样接上非线性，下一节继续讨论。

1. Linear(2,3) 有多少参数，增加样本数会增加参数吗？**答：含偏置共 9 个；不会。**
2. 到 z 的导数是 2，连接 x 的权重是 0.1，传给 x 多少？**答：0.2，还要乘局部导数。**
3. 共享权重总梯度为 0，说明每条样本都没有贡献吗？**答：不一定，也可能相互抵消。**
4. 损失已 mean，反向后还要再除 batch size 吗？**答：不需要，缩放已通过计算图传入。**
