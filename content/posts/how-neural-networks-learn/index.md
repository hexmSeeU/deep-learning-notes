第 01 课 · 从一次预测，到第一次参数更新。你不需要先学完微积分，我们用具体数字看清“学习”发生在哪里。

> **本课目标：** 读完后，你应该能解释参数、预测、loss、梯度和学习率，手算一次更新，并指出训练代码中哪一行真正改变了模型。

## 1. “学会了”究竟指什么？

假设我们观察到三组输入和输出：

| 输入 x | 目标 y |
| --- | --- |
| 0 | 1 |
| 1 | 3 |
| 2 | 5 |

你很容易发现规律 `y = 2x + 1`。模型一开始不知道这个规律。我们先给它一个可调整的函数：

{{< equation >}}ŷ = wx + b{{< /equation >}}

`ŷ`（读作 y hat）是模型的预测；`w` 是权重，决定输入的影响；`b` 是偏置，决定整体平移。**学习，就是利用数据调整 w 和 b，让预测更符合目标。**

这里先用线性回归暴露训练机制。它可以看成一个没有非线性激活的单神经元模型，还不是深层神经网络。第 7 节再把它连接到真正的非线性网络。

| 符号 | 本课含义 | 由谁决定 |
| --- | --- | --- |
| x、y | 输入和监督目标 | 数据提供 |
| w、b | 模型参数 | 训练更新 |
| ŷ | 模型的预测 | 前向计算 |
| L | 衡量预测误差的标量 | 目标函数定义 |
| ∂L/∂w、∂L/∂b | loss 对参数的局部变化率 | 反向传播计算 |
| η | 学习率，控制更新步幅 | 人为设置的超参数 |

## 2. 用 loss 衡量错得有多远

先只看一条数据：`x = 1，y = 2`。注意：这是一条专门用于手算的样本，与前面三条训练数据分开。

初始化 `w = 0，b = 0`，前向计算得到 `ŷ = 0`。我们定义平方误差：

{{< equation >}}L = ½(ŷ − y)²{{< /equation >}}

所以 `L = ½ × (0 − 2)² = 2`。平方让正负误差都产生非负损失；前面的 `½` 只是方便求导，不是神经网络训练的必需规定。

**loss 是我们选择的训练目标。** 它不是模型对世界的完整理解，也不自动等于实际任务的质量。这里选平方误差，后续分类和语言模型会学习交叉熵。

## 3. 梯度告诉我们：往哪里调整？

先做一个小预测：目标是 2，当前预测是 0，把 w 稍微增大，loss 会怎样变化？在当前位置，预测更接近目标，loss 会下降。

导数把这种局部关系量化。`∂L/∂w` 表示：固定其他参数，当 w 发生一个很小的变化时，L 大约变化多少。

{{< equation >}}ΔL ≈ (∂L/∂w) · Δw{{< /equation >}}

这是局部近似，变化太大时不能照搬。多个参数的偏导数组成梯度。用链式法则把计算过程拆开：

```text
ŷ = wx + b
L = ½(ŷ − y)²

∂L/∂ŷ = ŷ − y
∂ŷ/∂w = x       ∂ŷ/∂b = 1

∂L/∂w = (ŷ − y)x
∂L/∂b = ŷ − y
```

在 `x=1，y=2，w=b=0` 时，两个梯度都是 `−2`。负号表示：在当前位置，增大对应参数会降低 loss。

**反向传播（backpropagation）** 就是沿计算过程反向应用链式法则，高效求出这些梯度。它负责计算，参数更新由优化器负责。

## 4. 第一次更新，亲手算出来

使用最基本的梯度下降：

{{< equation >}}参数的新值 = 参数的旧值 − 学习率 × 梯度{{< /equation >}}

取学习率 `η = 0.1`：

```text
w_new = 0 − 0.1 × (−2) = 0.2
b_new = 0 − 0.1 × (−2) = 0.2

更新后 ŷ = 0.2 × 1 + 0.2 = 0.4
更新后 L = ½ × (0.4 − 2)² = 1.28
```

loss 从 `2` 降到 `1.28`。模型的“学习”就发生在参数由 `(0, 0)` 变成 `(0.2, 0.2)` 的这一步。

两个参数都用**同一次前向计算对应的梯度**更新。不要先改 w，再在新 w 上计算 b 的梯度，除非你明确要实现另一种更新算法。

## 5. 从一条样本到一批数据

现在回到开头的三条数据。我们优化整个批次的平均损失，N 表示样本数量：

{{< equation >}}L = 1/(2N) Σᵢ (wxᵢ + b − yᵢ)²{{< /equation >}}

对应梯度也是每条样本梯度的平均：

```text
∂L/∂w = (1/N) Σᵢ (wxᵢ + b − yᵢ)xᵢ
∂L/∂b = (1/N) Σᵢ (wxᵢ + b − yᵢ)
```

从 `w=b=0` 开始，初始 loss 为 `35/6 ≈ 5.833333`；`∂L/∂w = −13/3`，`∂L/∂b = −3`。学习率为 0.1 时，第一次更新得到 `w≈0.433333，b=0.3`，loss 约为 `3.387037`。

下面实验与这三条数据、这个平均损失完全一致。它使用显式梯度公式；运行过程全部在你的浏览器中。

### 最小 Python 实验

不需要 GPU，也不需要 PyTorch：

```bash
python examples/first_training.py --lr 0.1 --steps 100
python examples/first_training.py --lr 0 --steps 10
python examples/first_training.py --lr 1 --steps 10
```

核心循环如下；完整源码可以在本节下载。

```python
data = [(0., 1.), (1., 3.), (2., 5.)]
w, b, lr = 0., 0., 0.1
for step in range(100):
    errors = [(x, w*x + b - y) for x, y in data]
    dw = sum(e*x for x, e in errors) / len(data)
    db = sum(e for x, e in errors) / len(data)
    w, b = w - lr*dw, b - lr*db
```

100 次更新后约为 `w=1.9877，b=1.0171，L=0.000062`。这些数字来自附带实验，保留四位小数会有舍入误差。这里每步使用全部三条数据；大数据集通常每步使用一个 mini-batch。

## 6. PyTorch 帮我们完成了哪些工作？

下面代码对应相同的数据和目标，`x`、`y` 都是 `[3, 1]`：3 个样本，每个样本 1 个数。保持预测与目标形状一致，避免广播悄悄改变你要优化的问题。

```python
x = torch.tensor([[0.], [1.], [2.]])
y = torch.tensor([[1.], [3.], [5.]])
model = torch.nn.Linear(1, 1)  # w: [1, 1]，b: [1]
with torch.no_grad():
    model.weight.zero_()
    model.bias.zero_()
optimizer = torch.optim.SGD(model.parameters(), lr=0.1)

for _ in range(100):
    optimizer.zero_grad()
    pred = model(x)
    loss = ((pred - y) ** 2).mean() / 2
    loss.backward()
    optimizer.step()
```

`model(x)` 进行前向计算；`loss.backward()` 计算并累积参数梯度；`optimizer.step()` 才更新参数。通常每步先 `zero_grad()` 清除上一步梯度；如果有意做梯度累积，则会采用不同的清零频率。

PyTorch 的 `MSELoss()` 默认是均方误差，没有本课的 `½`；要对齐这里的数值，需要再除以 2。整体缩放 loss 会缩放梯度，在相同学习率下影响更新幅度。

自动求导机制可继续阅读 [PyTorch 官方 autograd 教程](https://docs.pytorch.org/tutorials/beginner/basics/autogradqs_tutorial.html)。完整可运行版本：[PyTorch 实验](first_training_torch.py)。

## 7. 从线性模型到神经网络

把函数换成一个带隐藏层的网络：

```text
x → 线性变换 W₁x+b₁ → ReLU → 线性变换 W₂h+b₂ → ŷ
```

`ReLU(z) = max(0, z)` 是非线性激活。**没有非线性，多个线性层的组合仍然只能表示一个仿射变换。** 加入激活后，网络才有能力表达更复杂的关系。

例如一个隐藏神经元：`ŷ = v · ReLU(wx+b) + c`。它有四个标量参数 `w、b、v、c`。在 `x=1，y=2，w=1，b=0，v=1，c=0` 时：

```text
z=1，h=ReLU(z)=1，ŷ=1，L=0.5
∂L/∂ŷ = -1
∂L/∂v = -1，∂L/∂c = -1
∂L/∂h = -1，ReLU 在 z=1 的导数为 1
∂L/∂w = -1，∂L/∂b = -1
```

学习率 0.1 时四个参数同时更新到 `w=1.1，b=0.1，v=1.1，c=0.1`，预测变成 `1.42`，loss 变成 `0.1682`。网络更复杂了，**前向 → loss → 反向 → 更新** 的主线没有改变。

但如果 `z<0`，ReLU 这条路径的导数为零，传给 w、b 的梯度就可能为零。这是后面学习激活函数和初始化时会遇到的问题。

## 8. loss 降低，是否就代表学会了？

本课的数据无噪声，而且恰好符合线性关系，所以非常容易拟合。真实研究里还需要追问：

- 能否预测**没有参加训练的数据**？这涉及泛化与训练/验证/测试集划分。
- loss 是否反映真正关心的任务质量？还需要独立评价指标。
- 改进是否来自方法本身？要控制数据、训练预算、随机性等因素。
- 优化是否稳定？梯度下降并不保证任意步长下每步都降低 loss。

一个样本也不能唯一确定 w 和 b：在手算样本中，只要 `w+b=2` 就能得到零误差。数据与模型共同影响哪些参数能被确定。

后续会学习张量、shape 与广播，解释为什么 `[3]` 和 `[3,1]` 相减可能得到 `[3,3]`。完整依赖关系见[学习路线]({{< relref "/roadmap" >}})。

## 9. 小结与自检

学习的核心循环是：前向预测 → 计算 loss → 反向求梯度 → 更新参数。loss 降低还需要独立评估来检验泛化。

### 1. 把 backward() 执行十次，不调用 step()，参数会改变吗？

**参考答案：** 对本课标准代码而言，不会。backward 计算并累积 .grad，step 才修改参数。梯度本身可能变大，但参数尚未更新。

### 2. 单样本例子中，学习率改成 0.5，下一次预测和 loss 是多少？

**参考答案：** w=b=1，预测为 2，loss 为 0。这只是该样本上的结果，不能推出 0.5 适合其他数据或网络。

### 3. 为什么更新公式里是减去梯度？

**参考答案：** 梯度指向当前位置 loss 增长最快的方向。在足够小的步长下，沿负梯度方向可以降低 loss。它不是对大步长的保证。

### 4. loss 已经很小，还需要验证集吗？

**参考答案：** 需要。训练误差说明对已见数据的拟合情况；独立验证数据帮助评估泛化、选择超参数。最终测试集不应反复用于调参。

### 5. 你能不看代码，写出训练循环的四个核心步骤吗？

**参考答案：** 前向预测 → 计算 loss → 反向计算梯度 → 优化器更新参数。通常还需在合适的时机清零梯度。
