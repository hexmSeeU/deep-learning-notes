[上一节的 MLP]({{< relref "/posts/mlp" >}})输出一个回归预测值。现在换成分类：**网络先给类别打分，损失根据真实标签指导这些分数，再把梯度传回各层。** 本篇只讨论每条样本属于一个类别的情况。

## 1. Logits 是原始分数，不是类别编号或概率

假设类别顺序固定为 0=猫、1=狗、2=鸟。最后一个 Linear 输出三个数：

```text
z=[2.0,1.0,−0.5]
```

z 就是 logits，每个位置对应一个类别的原始分数。猫分数最高，因此预测类别编号为 0。

Logits 可以为负、可以大于 1，也不要求总和为 1。例如 [−3,−1,−2] 仍能选出狗，因为第二个位置的 −1 最大。

**三个输出单元分别给三类打分，不是用一个数回归出编号 0、1、2。** 编号只是约定的位置。

## 2. Softmax 把分数变成一组概率

```text
pᵢ = e^zᵢ / Σⱼ e^zⱼ
```

对 logits=[2,1,0]：

| 类别 | 指数值，约数 | 概率，约数 |
| --- | ---: | ---: |
| 猫 | 7.389 | 0.665 |
| 狗 | 2.718 | 0.245 |
| 鸟 | 1 | 0.090 |

概率均为正、总和为 1，分数顺序不变。三个分数相同，每类都是 1/3。模型给出 0.9，并不单独保证类似预测恰好 90% 正确，还要看模型学得怎样。

### 相对差异比绝对数值重要

[2,1,0]、[102,101,100]、[0,−1,−2] 的 Softmax 完全相同：

```text
e^(zᵢ+c) / Σⱼ e^(zⱼ+c)
= e^c×e^zᵢ / (e^c×Σⱼ e^zⱼ)
= e^zᵢ / Σⱼ e^zⱼ
```

共同平移抵消了。某个 logit 很大，不代表概率一定高；[100,100,100] 仍各占 1/3。

## 3. 交叉熵关注真实类别得到多少概率

假设真实标签是狗，概率为 [0.665,0.245,0.090]：

```text
L=−ln(真实类别的概率)
 =−ln(p狗)
 ≈1.407
```

ln 是自然对数。真实类概率越高，损失越小：p=0.9、0.5、0.1 时，损失分别约 0.105、0.693、2.303。

即使当前预测为猫，也要取标签指定的狗的概率，不是取最大概率。

| 预测 | 猫 | 狗，真实类 | 鸟 | 交叉熵 |
| --- | ---: | ---: | ---: | ---: |
| A | 0.6 | 0.3 | 0.1 | 约 1.204 |
| B | 0.5 | 0.4 | 0.1 | 约 0.916 |

两次都错，准确率没变，但 B 给狗更多概率，损失更小。已经预测正确时，继续提高真实类概率，也会降低交叉熵，而准确率不变。

**准确率看最终对错，交叉熵提供连续变化的目标。**

## 4. 为什么所有 logits 都收到梯度？

虽然损失只写真实类概率，但狗的概率依赖所有分数：

```text
p狗=e^z狗/(e^z猫+e^z狗+e^z鸟)
```

固定猫、狗分数，只提高鸟分数，分母变大、狗概率下降、损失上升。其他类别也通过分母影响目标，这就是概率之间的竞争。

对一条样本，Softmax 配合交叉熵，梯度结果很简洁：

```text
∂L/∂z = p−y
```

这里 z 是 Softmax 前的原始分数，不是概率；y 暂用 one-hot 解释。真实是狗：

```text
p=[0.6,0.3,0.1]
y=[0,  1,  0  ]
梯度=[0.6,−0.7,0.1]
```

负梯度方向推动狗的分数增大、其他分数减小。但训练实际更新的是产生分数的共享参数，不是为每条样本独立保存 logits，所以不能保证其他样本同时改善。

### 接回 Linear 的参数梯度

设输出层接收 h=[2,1]，每个类别有自己的两个权重与偏置：

| 输出单元 | 权重梯度：上游导数×h | 偏置梯度 |
| --- | --- | ---: |
| 猫 | [1.2,0.6] | 0.6 |
| 狗 | [−1.4,−0.7] | −0.7 |
| 鸟 | [0.2,0.1] | 0.1 |

例如普通 SGD 学习率为 0.1，狗的偏置增加 0.07。分类损失没有改变 Linear 求导规则，只是提供新的上游导数，梯度也会继续传给隐藏层。

## 5. 多分类代码：训练直接传 logits

```python
import torch
from torch import nn

logits = torch.tensor([[2.0, 1.0, 0.0]], requires_grad=True)
target = torch.tensor([1], dtype=torch.long)

criterion = nn.CrossEntropyLoss()
loss = criterion(logits, target)
print(loss.item())  # 约 1.4076
loss.backward()
```

CrossEntropyLoss 内部组合相关计算，并采用数值稳定的实现。**不要先手动 Softmax，再把概率当作 logits 传进去。** 当前使用类别编号标签：

```text
logits.shape=(B,C)
target.shape=(B,)，整数编号
```

8 条、3 类对应 (8,3) 与 (8,)。不必手写 one-hot。接口要求可核对 [CrossEntropyLoss 官方文档](https://docs.pytorch.org/docs/2.15/generated/torch.nn.CrossEntropyLoss.html)。

训练与预测要分开：

```python
# logits 来自 model(x)，shape 为 (B,C)
predicted_class = logits.argmax(dim=1)  # (B,)
probs = torch.softmax(logits, dim=1)    # (B,C)
```

dim=1 是类别轴，每条样本内部比较。Softmax 不改变排序，只需要类别时，直接 argmax 即可；它返回离散编号，不是交给交叉熵训练的连续分数。

## 6. 二分类：一个 logit 加 Sigmoid

判断“有猫／没有猫”，可以只用一个输出单元。标签 1 表示有猫，0 表示没有：

```text
p=sigmoid(z)=1/(1+e^(−z))
```

p 是正类概率，负类概率是 1−p。z=−2、0、2 时，p 约为 0.119、0.5、0.881。选择 0.5 为阈值时，也可直接判断 z 是否达到 0。

这不是用一个数回归类别编号，而是用原始分数表达对正类的倾向。

二分类交叉熵同时覆盖两种标签：

```text
L=−[y ln(p)+(1−y)ln(1−p)]

y=1：L=−ln(p)
y=0：L=−ln(1−p)
```

本质仍是“取真实类概率的负对数”。p=0.8 时，真实有猫的损失约 0.223；真实没有猫则约 1.609。y=0 时，把 p 降到 0.2，损失就降到约 0.223。

### 对应的输出、标签和损失要配套

```python
logits = torch.tensor([[2.0]], requires_grad=True)
target = torch.tensor([[1.0]])

criterion = nn.BCEWithLogitsLoss()
loss = criterion(logits, target)
```

BCEWithLogitsLoss 内部组合 Sigmoid 和二分类交叉熵，也不应先手动做 Sigmoid。输入与标签 shape 相同，标签为浮点数。

| 当前用法 | 输出 | 标签 |
| --- | --- | --- |
| 三分类 CrossEntropyLoss | (B,3) logits | (B,) 整数类别编号 |
| 单 logit 二分类 BCEWithLogitsLoss | (B,1) logits | (B,1) 浮点数 0 或 1 |

## 7. 二分类也能使用两个 logits

若 z₀、z₁ 分别为负类和正类分数：

```text
p正=e^z₁/(e^z₀+e^z₁)
   =1/(1+e^(−(z₁−z₀)))
   =sigmoid(z₁−z₀)
```

因此，两个 logits=[1,3] 与单 logit=2，正类概率都约为 0.881；[5,5] 对应差值 0，概率为 50%。

两个 logits 配 CrossEntropyLoss、整数编号；一个 logit 配 BCEWithLogitsLoss、同 shape 浮点标签。概率表达可以对应，但参数化和优化过程不必相同，不能只换损失而忽略输出和标签。

## 小结与自检

```text
隐藏特征 → Linear 输出 logits → 对应分类损失 → 梯度传回网络
```

训练用原始分数，展示概率才做相应转换；类别编号是最终选择，不能与 logits、概率混为一谈。

1. logits 都为负，能选预测类吗？**答：能，选择最大值的位置。**
2. 准确率不变，交叉熵能下降吗？**答：能，真实类概率可能提高但尚未改变最大值位置。**
3. CrossEntropyLoss 前要先 Softmax 吗？**答：不要，当前接口直接接收 logits。**
4. 8 条单 logit 二分类，输出 (8,1)，标签怎样设置？**答：(8,1) 的浮点数 0 或 1。**
