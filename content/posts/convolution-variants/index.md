[卷积基础]({{< relref "/posts/convolution-basics" >}})讲了局部计算与权重共享。理解卷积变体，关键是分开两个问题：**空间上看多大区域，通道上连接哪些输入。** 本篇沿用已讨论的例子，不提前展开新结构。

## 1. 1×1 不代表只有一个权重

某个位置有三个输入通道，数值为 [2,3,4]。普通 1×1 卷积的一个输出通道，可以用权重 [1,−1,2] 和偏置 1 计算：

```text
输出=1×2−1×3+2×4+1=8
```

1×1 指空间窗口，只看当前位置；但通道方向仍组合全部三个输入。

```text
空间：不看邻居
通道：把当前位置的多个数加权组合
```

三进五出的普通 1×1 卷积，权重 shape 为 (5,3,1,1)，共有 15 个权重。**含偏置还要加五个，共 20 个参数**，不是 15。

当 stride=1、padding=0：

```text
输入 (8,3,5,5) → 输出 (8,5,5,5)
改成两个输出通道 → 输出 (8,2,5,5)
```

各位置不混合，所有位置共用同一个通道变换，类似把同一个 Linear(3,5) 用在每个位置。增加通道提供新表示，但输出仍来自原有输入，不是凭空得到额外观测。

## 2. Groups 是组数，不是每组通道数

普通卷积每个输出看全部输入通道。分组卷积只连接本组输入。例如四进四出、groups=2：

```text
输入 1、2 → 输出 1、2
输入 3、4 → 输出 3、4
```

两组独立，输入通道 1 的变化，不直接影响输出通道 3。空间核仍可为 3×3，改变的是通道连接。

```text
每组输入通道数=总输入通道数/groups
每组输出通道数=总输出通道数/groups
```

因此标准分组卷积要求输入、输出通道数都能被 groups 整除。八进十出不能设置 groups=4，因为输出无法等分。

尤其要记住：**groups=1 是所有通道在同一组，不是每组只有一个通道。** 八个输入、groups=1，每个输出能看全部八个输入；这正是普通卷积。

## 3. 权重 shape 为什么没有额外的组轴？

分组卷积保存的权重为：

```text
(输出通道数, 输入通道数/groups, 核高, 核宽)
```

四进四出、两组、3×3 核，对应 (4,2,3,3)。每个输出用两片 3×3 权重，不是四片。空间核大小与完整权重 shape 是不同概念。

组数保存在层的配置 groups 中，不必成为权重额外的一根轴。按输出排列，前两个输出属于第一组，后两个属于第二组。

**只看 (4,2,3,3) 不能唯一确定组数。** 它也可能来自二进四出、groups=1；完整计算由权重与层配置共同确定。

### 参数量：不要重复乘组数

```text
权重数量=输出通道数×(输入通道数/groups)×核高×核宽
含偏置再加：输出通道数
```

八进十二出、groups=4、3×3 核：每组两个输入、三个输出，总权重 shape 为 (12,2,3,3)。

```text
按所有输出算：12×2×3×3=216
按组算：每组 3×2×3×3=54，四组为 216
再加 12 个偏置，总计 228
```

第一维 12 已包含四组的全部输出，不能再乘四次。普通卷积则是 12×8×3×3+12=876。

分组减少参数，也限制跨组信息组合。更少参数不保证更好的表达或预测效果。

## 4. 深度卷积：每组只有一个输入通道

令 groups 等于输入通道数，先看四进四出：

```text
输入 1 → 输出 1
输入 2 → 输出 2
输入 3 → 输出 3
输入 4 → 输出 4
```

每个通道有自己的一片 3×3 核，空间位置之间共享，但不同通道不共享：

```text
权重 shape=(4,1,3,3)
含偏置参数量=4×1×3×3+4=40
```

它做空间局部处理，不做跨输入通道混合。

### 一个输入也可以产生多个输出

四个输入、groups=4，也可以产生八个输出：

```text
输入 1 → 输出 1、2
输入 2 → 输出 3、4
输入 3 → 输出 5、6
输入 4 → 输出 7、8
```

每个输入用两片独立核提取两种响应。每个输入产生几个输出，叫 depth multiplier，本例为 2。

```text
权重 shape=(8,1,3,3)
含偏置参数量=8×1×3×3+8=80
```

Multiplier=3 时输出十二个通道，groups 仍为 4。增加空间响应数量，不等于开始混合不同输入通道，也不保证保留全部信息。

## 5. 深度卷积之后，1×1 混合的是什么？

四个输入通道先经 multiplier=1 的深度卷积，再接普通 1×1，输出八个通道：

```text
4 通道 → 各自做 3×3 空间处理 → 4 个中间通道
       → 普通 1×1 通道混合 → 8 个输出通道
```

这个组合叫深度可分离卷积。这里不额外插入激活或归一化，只看两步卷积的分工。

两层都含偏置时：

```text
深度层：4×1×3×3+4=40
1×1 层：8×4×1×1+8=40
合计 80

普通四进八出 3×3：8×4×3×3+8=296
```

为什么参数更少？它先把每个输入通道局部区域提取成中间数，再组合这些数。

```text
A → 空间核 → A′ ──┐
B → 空间核 → B′ ──┼→ 1×1 加权组合 → 输出
C → 空间核 → C′ ──┘
```

**后面的 1×1 看的是 A′、B′、C′，不能绕过前一步重新访问原始局部。**

## 6. 一个具体例子：丢掉的区别不能重新恢复

先只看输入通道 A 的一个区域：

```text
区域：       深度核 K：
1 2          1  0
3 4          0 −1

A′=1−4=−3
```

后面的 1×1 收到一个数 −3，不是原来的四个数。暂不加偏置，两个输出可分别算 2A′=−6、−A′=3。

比较另一块区域 [[1,9],[3,4]]，经过同一个 K，A′仍为 −3。只凭这个中间数，后面的 1×1 无法区分它们。

但普通卷积可以为另一个输出单独设置核 [[0,1],[0,0]]，直接读右上角，两个区域分别得到 2、9。

更一般地，multiplier=1 时，输入 A 先只经过一片空间核 K；它对后续两个输出的等效空间核只能是 αK、βK。普通卷积则可以分别学习独立的 K₁、K₂。

**更少自由度换来更少参数与计算，不保证能替代任意普通卷积。** Multiplier 增大后可先保留更多空间响应，但仍需按具体结构判断能力。

多输入通道时也要注意范围：只有整组中间结果 [A′,B′,C′] 相同，后续 1×1 才一定无法区分。仅 A′相同不够，其他通道可能保留了区别。

## 7. 空间核与通道分组，是两个独立配置

| 结构 | 空间范围 | 通道连接 |
| --- | --- | --- |
| 普通 3×3 | 局部 3×3 | 每个输出看全部输入 |
| 普通 1×1 | 当前位置 | 每个输出看全部输入 |
| 分组卷积 | 由核大小决定 | 只连接组内输入 |
| 深度卷积 | 由核大小决定 | 每组一个输入，可有多个输出 |

1×1 也可以分组。四进四出、1×1、groups=4 时，每个通道只计算“自身输入×权重+偏置”，既不混空间，也不混通道。

因此前面说 1×1 负责混合全部中间通道，指的是 **groups=1 的普通 1×1**。

```text
groups=1：普通卷积，全部通道一组
1<groups<输入通道数：分组连接
groups=输入通道数：深度卷积，输出为输入通道数的整数倍
```

这些是同一套连接规则的不同配置，不是彼此无关的运算。

## 小结与自检

先看空间核，再看 groups；参数量按实际连接计算。深度卷积先按通道提取空间响应，普通 1×1 再混合提取结果。

1. groups=1，表示每组一个输入吗？**答：不是，表示全部输入在同一组。**
2. 八进十二出、四组、3×3，含偏置多少参数？**答：12×2×3×3+12=228。**
3. 四个输入、multiplier=3 的深度卷积，输出和 groups 是多少？**答：输出 12，groups=4。**
4. 只有 A′相同，后续 1×1 一定无法区分两个输入吗？**答：不一定，要整组中间结果相同。**
