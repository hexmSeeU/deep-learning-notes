一个数变化一点，会让函数值变化多少？如果同时改变多个数，又怎样估计它们的共同影响？

这一篇先只研究普通函数，从最简单的直线开始。**导数和梯度描述函数怎样变化；至于要不要据此修改变量，是另一件事。**

## 1. 从直线的变化率开始

设 `y = 2x + 1`。当 x 从 3 增加到 4，y 从 7 增加到 9：

```text
Δx = 4 − 3 = 1
Δy = 9 − 7 = 2

Δy / Δx = 2
```

`Δ` 表示改变量。这个比值回答：在这段变化里，输出的改变量是输入改变量的多少倍？

若 x 只增加 0.1，y 就增加 0.2，比值仍为 2。对这条直线，无论从哪个位置出发，变化率都一样。它对 x 的导数写成：

{{< equation >}}dy/dx = 2{{< /equation >}}

先把 `dy/dx` 理解成“y 对 x 的局部变化率”。对直线来说，它就是处处相同的斜率。换成 `y = 3x + 5`，导数为 3；x 增加 0.1，y 就增加 0.3。

## 2. 曲线的导数为什么随位置改变？

看 `y = x²`，先站在 x=3 的位置，此时 y=9。尝试越来越小的输入变化：

| x 的变化 | y 的变化 | Δy / Δx |
| --- | --- | ---: |
| `3 → 4` | `9 → 16`，增加 7 | 7 |
| `3 → 3.1` | `9 → 9.61`，增加 0.61 | 6.1 |
| `3 → 3.01` | `9 → 9.0601`，增加 0.0601 | 6.01 |

**步子越小，比值越接近 6。** 这个趋近的值，就是 x² 在 x=3 处的导数。把改变量记作 Δx，可以算出：

```text
Δy / Δx
= [(3 + Δx)² − 3²] / Δx
= [6Δx + (Δx)²] / Δx
= 6 + Δx
```

这里 Δx 不为 0，才能约去它；随后让它越来越接近 0，比值便越来越接近 6。不是直接拿 0 去做分母。

把 3 换成任意位置 x，同样得到：

```text
[(x + Δx)² − x²] / Δx = 2x + Δx
```

所以 `y=x²` 的导数是 `dy/dx=2x`，也常写作 `f′(x)=2x`。导数本身是一条随位置变化的规则：x=2 时为 4，x=3 时为 6，x=10 时为 20。

这也说明它的边界：在 x=2 处导数为 4，不代表从 2 一直走到 3，函数值就只增加 4。实际增加的是 `3²−2²=5`。**导数说的是当前位置附近，不是任意大的一段变化。**

## 3. 用导数估计一个小变化

导数的用途可以写成一个局部近似：

{{< equation >}}Δy ≈ (dy/dx) × Δx{{< /equation >}}

注意是“约等于”。对 x²，在 x=2 处，若 x 增加 0.01：

```text
估计：Δy ≈ 4 × 0.01 = 0.04
实际：2.01² − 2² = 0.0401
```

两者很接近，但不完全相等，因为变化过程中斜率也在改变。

再到 x=−2 处，此时导数为 −4。x 同样增加 0.01，估计函数值变化为 `−4×0.01=−0.04`，也就是减小。实际从 4 降到 3.9601，变化为 −0.0399。

因此，导数的符号与大小分别有这样的含义：

- **正负号描述局部方向**：导数为正时，x 稍微增大，函数值也增大；导数为负时，x 稍微增大，函数值减小。
- **绝对值描述局部敏感程度**：相同的微小输入变化下，导数绝对值越大，输出变化通常越明显。

导数的正负不是函数值的正负。x² 在 x=2 和 x=−2 处的函数值都为 4，导数却分别是 4 和 −4。方向判断还要结合输入改变量：输入若减小，Δx 本身就是负数。

## 4. 偏导数：一次只研究一个变量

如果函数同时依赖两个量，例如：

{{< equation >}}f(w, b) = w² + 3b{{< /equation >}}

问“w 改变一点，f 会怎样变化”时，要先明确 b 是否也在变化。**偏导数的约定是：研究一个变量时，暂时固定其他变量。**

- 固定 b，`3b` 是常数，f 对 w 的偏导数为 `∂f/∂w = 2w`。
- 固定 w，`w²` 是常数，f 对 b 的偏导数为 `∂f/∂b = 3`。

这里 `∂` 是偏导数符号。它强调这是多变量函数里，某一个变量单独变化产生的影响。w 和 b 在这里仅仅是两个自变量的名字。

在 w=2、b=1 处：

| 单独改变谁 | 对应偏导数 | 该变量增加 0.01 时，f 的变化 |
| --- | ---: | --- |
| w，固定 b | 4 | 约增加 0.04 |
| b，固定 w | 3 | 增加 0.03 |

换到 w=−2、b=1 处，对 w 的偏导数变成 −4，对 b 的偏导数仍为 3。同一个函数，不同变量的影响不同；同一个变量的影响，也可能随位置改变。

## 5. 梯度：把各变量的偏导数组合起来

按变量顺序 `(w, b)` 排列各偏导数，就得到**梯度（gradient）**：

```text
∇f = [∂f/∂w, ∂f/∂b]
   = [2w, 3]
```

`∇f` 读作“f 的梯度”。在 w=−2、b=1 处，梯度是 `[-4, 3]`。它不是把偏导数相加成 −1，而是**保留每个变量对应的分量和顺序**。

如果两个变量同时发生很小的变化，可以把各自的影响相加：

{{< equation >}}Δf ≈ (∂f/∂w)Δw + (∂f/∂b)Δb{{< /equation >}}

例如在这个位置：

```text
Δw = 0.01，Δb = 0.01
Δf ≈ −4×0.01 + 3×0.01 = −0.01

Δw = 0.01，Δb = −0.01
Δf ≈ −4×0.01 + 3×(−0.01) = −0.07
```

第一种变化里，两个变量的影响部分抵消；第二种里，两者都让函数值减小。

还记得[上一节的点积]({{< relref "/posts/matrix-multiplication-and-linear-layers" >}})吗？把改变量也按相同顺序组成向量 `Δθ=[Δw, Δb]`，上式就是：

{{< equation >}}Δf ≈ ∇f · Δθ{{< /equation >}}

θ 在这里只是“把所有自变量放在一起”的简写。梯度与改变量必须采用相同的排列顺序，点积才能对应正确。

## 6. 为什么沿负梯度走一小步？

如果现在的目标是**让 f 的值变小**，就希望局部近似中的点积为负。一个直接的选择是：

{{< equation >}}Δθ = −η∇f，η > 0{{< /equation >}}

η 是控制步幅的系数。梯度本身描述函数的变化，而这条规则决定我们怎样改变变量，二者不是同一个概念。

仍在梯度为 `[-4, 3]` 的位置，取 η=0.01：

```text
Δw = −0.01×(−4) =  0.04
Δb = −0.01×3    = −0.03

Δf ≈ (−4)×0.04 + 3×(−0.03) = −0.25
```

增大 w、减小 b，两个变化都帮助 f 降低。反过来沿正梯度方向走，即 `Δw=−0.04、Δb=0.03`，估计变化就是 +0.25。

一般地，把负梯度方向的改变量代入：

```text
Δf ≈ −η[(∂f/∂w)² + (∂f/∂b)²]
```

平方项非负，所以梯度非零时，这个一阶近似给出的变化为负。对这里的可导函数，沿负梯度走足够小的一步可以降低函数值；**迈得太大，局部近似就不保证有效。**

## 7. 梯度为零，不等于找到了最小值

比较两个普通函数：`f(x)=x²` 与 `g(x)=−x²`。导数分别为 `2x` 和 `−2x`，在 x=0 处都为 0，但附近的情况相反：

| x | f(x)=x² | g(x)=−x² |
| --- | ---: | ---: |
| −0.1 | 0.01 | −0.01 |
| 0 | 0 | 0 |
| 0.1 | 0.01 | −0.01 |

对 f，离开 0 会变大，这里是最小值；对 g，离开 0 反而变小，这里是最大值。**同样的零导数，可能对应谷底，也可能对应山顶。**

原因在于，导数提供的是一阶局部信息。对 x²，在 0 处的近似是 `Δf≈0×Δx=0`，实际变化却为 `(Δx)²`。它通常不为 0，只是在步幅很小时，比一次方的变化更小，没有被这个一阶近似体现出来。

因此，梯度为零只说明当前位置各变量的一阶变化率为零，不能单凭它判定函数值已经最小。

## 8. 自变量是矩阵时，梯度也按位置排列

如果一个标量函数依赖矩阵 W 中的各个数，可以对每个元素求偏导：`∂f/∂Wᵢⱼ`。它表示固定其他元素，只研究第 i 行、第 j 列的数对 f 的影响。

把偏导数放回对应位置，就得到与 W **shape 相同**的梯度张量。比如 W 的 shape 为 `(64, 128)`，对应梯度也是 `(64, 128)`，不是一个单独的数。

假设在某个位置算出的梯度 G 为：

```text
W = [[1, 2],       G = [[0.1, −0.2],
     [3, 4]]            [0.0,  0.3]]
```

取 η=0.1，按负梯度规则更新：

```text
W_new = W − 0.1 * G
      = [[0.99, 2.02],
         [3.00, 3.97]]
```

这是逐元素相减，不是矩阵乘法：每个数使用自己对应的偏导数。数学上可以把所有自变量排成一个大向量；代码里保留张量原来的 shape，更方便一一对应。

## 小结与自检

从一个变量到多个变量，主线始终是**局部变化**：导数描述单变量变化率；偏导数固定其他变量；梯度把各分量组合起来，用点积估计共同影响。

1. x² 在 x=−3 处，x 增加 0.01，函数值大约怎样变化？**答：导数为 −6，约减少 0.06。**
2. 对 `f(w,b)=w²+3b`，在 w=−2、b=1 处，梯度是什么？**答：按 `(w,b)` 的顺序是 `[-4,3]`。**
3. 同一位置，w 增加 0.01、b 减少 0.01，f 大约变化多少？**答：−0.07；这是局部估计，不是任意大变化下的精确值。**
4. 梯度为零能直接说明是最小值吗？**答：不能，x² 与 −x² 在 0 处的导数都为零，却分别是最小值和最大值。**
