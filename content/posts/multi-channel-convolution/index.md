[上一节]({{< relref "/posts/convolution-basics" >}})用单通道小矩阵讲了局部连接与共享权重。实际图像往往有多个通道，这一节把三个问题分开：**通道怎样连接，窗口在哪里计算，最终输出有多大。**

本篇均讨论不分组、核内位置连续的普通二维卷积，padding 使用对称补零。后面的公式不提前包含其他卷积变体。

## 1. 一个输出通道，会组合全部输入通道

RGB 图片的 R、G、B 各是一张二维表。如果用 2×2 核产生一个输出通道，就需要：

```text
R 通道：一片 2×2 权重
G 通道：一片 2×2 权重
B 通道：一片 2×2 权重
```

这三片共同组成一套权重。在每个空间位置，分别对三个局部区域加权求和，再把结果相加：

```text
R 局部加权结果 ──┐
G 局部加权结果 ──┼→ 相加，再加一次偏置 → 一个输出值
B 局部加权结果 ──┘
```

例如三个结果为 2、−1、4，偏置为 1，最终输出 6。

**不是三个输入通道各自留下一个输出通道，而是跨通道汇总成一个。** 偏置在汇总后加一次，不是每个输入通道都加一次。

## 2. 多个输出通道，需要多套独立权重

输入为三个通道，想得到两个输出通道：

```text
第 1 套：3 片 2×2 权重 + 1 个偏置 → 特征图 1
第 2 套：3 片 2×2 权重 + 1 个偏置 → 特征图 2
```

每套都看完整的三个输入通道，各自学一种局部组合。因此普通卷积的权重 shape 是：

```text
(输出通道数, 输入通道数, 核高度, 核宽度)
```

上例为 (2,3,2,2)，含偏置参数量为 2×3×2×2+2=26。

一般地：

```text
权重数量 = 输出通道数 × 输入通道数 × 核高度 × 核宽度
偏置数量 = 输出通道数
```

三个输入通道、五个输出通道、3×3 核，含偏置为 5×3×3×3+5=140。

**输出通道数不必等于输入通道数。** 它表示要计算多少种局部组合；后续特征图也不再天然对应 R、G、B。每套权重在空间位置与不同样本之间共享。

## 3. 通道数与空间大小，是两件事

假设输入 shape 为 (8,3,5,5)，分别表示样本数、通道数、高、宽。使用五个输出通道、3×3 核，每次移动一格、不补边缘。

只看长度方向：

```text
输入位置：1 2 3 4 5
窗口 1： [1 2 3]
窗口 2：   [2 3 4]
窗口 3：     [3 4 5]
```

高、宽各放三个位置，所以输出 shape 为 (8,5,3,3)。

改成十个输出通道，就变成 (8,10,3,3)，空间仍是 3×3。八条样本各自计算，不相互混合，也不会各自拥有一套独立权重。

## 4. Stride：窗口每次移动几格

stride=2 时，同样长度为 5、核长度为 3：

```text
窗口 1：[1 2 3]
窗口 2：    [3 4 5]
```

只产生两个输出。若高、宽都如此，输入 (8,3,5,5)、输出通道十个，输出就是 (8,10,2,2)。

**步幅改变核的使用位置，不改变权重数量。** 输入输出通道与核大小不变，stride 从 1 改成 2，参数量不变。

### 窗口不完整，就不会再产生输出

长度改为 6，核长度仍是 3，stride=2、不填充：

```text
窗口起点 1：覆盖 1、2、3
窗口起点 3：覆盖 3、4、5
下个起点 5：需要 5、6、7，但输入没有第 7 个位置
```

所以仍只有两个输出；第 6 个输入位置在这个例子中没有被任何窗口覆盖。

公式中的向下取整正是表达这件事：

```text
输出长度 = floor((输入长度−核长度)/stride)+1

长度 6、核 3、步幅 2：floor(1.5)+1=2
```

floor 表示向下取整。高、宽各算一次，6×6 输入就得到 2×2 输出。

## 5. Padding：边缘补值，改变可用的窗口位置

padding=1 表示每个空间方向两侧各补一格。以补零为例：

```text
原输入：           补零后：
1 2 3             0 0 0 0 0
4 5 6             0 1 2 3 0
7 8 9             0 4 5 6 0
                  0 7 8 9 0
                  0 0 0 0 0
```

3×3 变成 5×5，再用 3×3 核、stride=1，输出从不填充时的 1×1 变成 3×3。

补出来的零是人为边界设定，不是真实图像内容，也不是可学习参数。填充让更多边缘窗口可以计算，但不保证所有配置都保持原尺寸。

加入对称填充后：

```text
输出长度 = floor((输入长度+2×padding−核长度)/stride)+1
```

两侧各补 padding，所以是加 2×padding。

| 输入 | 核 | stride | padding | 输出空间 |
| --- | --- | ---: | ---: | --- |
| 5×5 | 3×3 | 1 | 1 | 5×5 |
| 5×5 | 3×3 | 2 | 1 | 3×3 |
| 5×5 | 3×3 | 2 | 0 | 2×2 |
| 5×5 | 3×3 | 1 | 0 | 3×3 |

讨论中容易误记为“padding 少 1，输出就少 1”。看表可知：stride=2 时，3×3 变成 2×2，高宽各少 1；stride=1 时，5×5 变成 3×3，高宽各少 2。**必须代入公式，不能只看 padding 的变化。**

输入输出通道和核大小固定，填充仍不改变参数量。例如三进十出、3×3 核，含偏置始终为 280。

## 6. 高与宽分别计算，不要求正方形

考虑：

```text
输入：(8,3,6,8)
输出通道：4
核大小：(3,2)
stride：(2,2)
padding：(1,0)  # 上下各补 1，左右不补
```

高度方向：

```text
floor((6+2×1−3)/2)+1=3
```

宽度方向：

```text
floor((8+2×0−2)/2)+1=4
```

因此：

```text
输出 shape：(8,4,3,4)
权重 shape：(4,3,3,2)
偏置 shape：(4,)
参数量：4×3×3×2+4=76
```

输出 shape 描述本批结果，权重 shape 描述层保存的独立参数，不能混淆。Batch 改为 16，输出变成 (16,4,3,4)，权重不变。

## 7. 对应到 Conv2d 的配置

```python
import torch
from torch import nn

conv = nn.Conv2d(
    in_channels=3,
    out_channels=4,
    kernel_size=(3, 2),
    stride=(2, 2),
    padding=(1, 0),
)

x = torch.randn(8, 3, 6, 8)
y = conv(x)

print(y.shape)            # torch.Size([8, 4, 3, 4])
print(conv.weight.shape)  # torch.Size([4, 3, 3, 2])
print(conv.bias.shape)    # torch.Size([4])
```

保持默认的普通卷积设置，不分组，核内位置连续，边缘补零。接口约定可核对 [Conv2d 官方文档](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Conv2d.html)。

创建时没有填写 batch 或图像高宽。同一个层可以处理不同样本数和空间尺寸，只要输入通道匹配、窗口能合法计算。

例如改为输入 (8,3,10,12)，输出高为 5、宽为 6，得到 (8,4,5,6)，权重仍为 (4,3,3,2)。若输入通道改成 5，就不能直接交给这个层，它只为三个输入通道准备了权重。

## 小结与自检

**通道决定连接，核大小决定局部窗口，stride 与 padding 决定窗口位置；这些共同决定输出。** 参数量则由输入输出通道、核大小与是否使用偏置决定，不随使用次数增加。

1. 三个输入通道各算完，得到几个输出通道？**答：对一套完整权重，跨通道求和后得到一个输出通道。**
2. stride 或 padding 改变，会增加核权重吗？**答：不会，前提是输入输出通道和核大小不变。**
3. 6×6 输入、3×3 核、stride=2、不填充，输出多大？**答：2×2，放不下的窗口不再计算。**
4. 同一层改用更大图像，权重 shape 自动变大吗？**答：不会，只增加使用位置；输入通道仍须匹配。**
