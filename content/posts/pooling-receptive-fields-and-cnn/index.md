前面讨论了卷积的局部计算、通道连接与步幅。本节把这些组件接起来：**怎样汇总空间信息，一个输出能看到多大区域，以及怎样得到最终分类分数。**

## 1. 池化：没有可学习权重的局部汇总

最大池化也是滑动窗口，但不做带权求和，而是按固定规则选最大值。输入为：

```text
1  3 │ 2  0
4  6 │ 5  1
─────┼─────
7  2 │ 8  3
0  1 │ 4  9
```

用 2×2 窗口、stride=2，四块最大值为 6、5、7、9，输出：

```text
6  5
7  9
```

空间从 4×4 变为 2×2，是一种下采样。它保留局部最强响应，不保留其他数值。左上换成 [[2,5],[0,6]]，结果仍是 6，说明不同区域可以得到同一输出。

平均池化换成取均值，同样输入、窗口和步幅，得到：

```text
3.5  2
2.5  6
```

最大池化强调最强响应，平均池化保留平均水平；有一个很大的值时，最大池化更容易被它主导。两种都无可学习权重、无偏置，不代表某一种总更好。

普通二维池化按通道分别处理，不跨通道取最大或平均：

```text
输入 (8,3,4,4) → 2×2 池化、stride=2 → (8,3,2,2)
输入 (16,32,8,8) → 同样池化 → (16,32,4,4)
```

样本数、通道数不变，缩小的是空间尺寸。

## 2. 没有参数，反向也不会停止

窗口 [[1,3],[4,6]] 的最大值唯一，为 6。若上游导数为 2，最大池化传回：

```text
0  0
0  2
```

在最大值位置不变的小范围内，调整其他三个数不影响输出，调整 6 才影响。因此梯度传给被选中的位置。并列最大值还涉及实现的选择规则，这里不展开。

平均池化中，每个数的系数都是 1/4，同样上游导数 2，就各得 0.5；上游为 8，则各得 2。

**池化不需要学习权重，但必须把梯度传给前面的特征。** 这些梯度还能继续经过卷积，让卷积参数学习，不能因为某层没有参数，就认为反向到此为止。

## 3. 感受野：结构上能依赖多大输入区域

连续两层 3×3 卷积，均 stride=1、不填充：

```text
原图 7×7 → 中间 5×5 → 输出 3×3
```

第一层一个位置看原图 3×3；第二层一个位置组合中间的 3×3 个位置。它们对应的原图区域重叠，合起来是 5×5，不是 6×6。

只看一维就清楚：

```text
中间位置 1 → 原图位置 1、2、3
中间位置 2 → 原图位置 2、3、4
中间位置 3 → 原图位置 3、4、5

组合三个中间位置 → 原图位置 1～5
```

再接一层同样卷积，感受野成为 7×7。

这里说的是计算结构上可能影响输出的范围，不表示范围内各输入当前贡献相同，也不能与输出特征图的尺寸混淆。

## 4. 关键纠正：位置间隔增大，直接来自 stride

讨论中曾把“池化后感受野扩大得快”说得不够准确。**直接让相邻特征对应的原图间隔变大的，是步幅，不是池化的身份。**

直接作用于原图时：

| 操作 | 单个输出感受野 | 相邻窗口起点间隔 |
| --- | --- | ---: |
| 2×2 池化，stride=1 | 2×2 | 1 |
| 2×2 池化，stride=2 | 2×2 | 2 |
| 2×2 卷积，stride=2 | 2×2 | 2 |

前一层为 2×2、stride=2 的池化时，三个相邻位置分别覆盖原图 1～2、3～4、5～6。后面 3×3 卷积组合它们，感受野是 6×6。

若前面池化的 stride 改为 1，三个窗口覆盖 1～2、2～3、3～4，最终只有 4×4。

### 把感受野和间隔分别记录

限定普通连续窗口，只看一个方向：

```text
r：上一层的感受野大小
j：上一层相邻位置在原图上的间隔
k：本层窗口大小
s：本层 stride

r新 = r+(k−1)×j
j新 = j×s
```

原输入从 r=1、j=1 开始。第一个选中位置已覆盖 r，另外 k−1 个每次扩展 j，所以是这条递推。

| 阶段 | 感受野 r | 间隔 j |
| --- | ---: | ---: |
| 原图 | 1 | 1 |
| 2×2 池化、stride=2 | 2 | 2 |
| 3×3 卷积、stride=1 | 6 | 2 |
| 再一层 3×3、stride=1 | 10 | 2 |

高、宽各算一次。不能无视之前的步幅，一律说每层 3×3 只增加 2。

## 5. 把卷积特征接成分类预测

用一个小 CNN 处理八张 RGB、8×8 图片，分三类：

| 操作 | 输出 shape |
| --- | --- |
| 输入 | (8,3,8,8) |
| 卷积 3→4，3×3、stride=1、padding=1 | (8,4,8,8) |
| ReLU | (8,4,8,8) |
| 最大池化 2×2、stride=2 | (8,4,4,4) |
| Flatten，保留 batch | (8,64) |
| Linear(64,3) | (8,3) |

每张图有 4×4×4=64 个特征值。Flatten 不加权、不丢元素，把通道和空间展开成一行，不能把 batch 也混进去。Batch 改为 16，结果为 (16,64)，不是把所有图片压成一行。

最后的 Linear 组合各通道、各位置的信息，输出 logits，再接已学的交叉熵：

```text
图像 → 卷积 → 非线性 → 下采样 → 分类分数
                                      ↓
                                  最终分类损失
                                      ↓
                               反向求导、参数更新
```

## 6. Flatten 与全局平均池化，保留的信息不同

另一条路线是把每个通道整张特征图平均，叫全局平均池化。对 (8,4,4,4)：

```text
每个通道 16 个数 → 一个平均值
(8,4,4,4) → (8,4,1,1) → 展开为 (8,4)
```

再接 Linear(4,3)。

| 路线 | 每张图送给 Linear 的数 | 分类层参数，含偏置 |
| --- | ---: | ---: |
| Flatten | 64 | 64×3+3=195 |
| 全局平均池化后展开 | 4 | 4×3+3=15 |

全局平均池化保留各通道的平均响应，舍弃具体位置排列。重排某个中间通道的 16 个值，平均不变；**这不代表移动原始图像，整个 CNN 的预测都不变**，前面的特征计算可能改变。

参数更少伴随信息组织方式变化，不是纯粹等价的代码替换。

## 7. 参数量与代码对照

Flatten 路线中，卷积含偏置为 4×3×3×3+4=112，Linear 为 195，共 307。ReLU、池化、Flatten 都没有参数。全局平均池化路线则共 112+15=127。

没有参数的组件仍改变表示或梯度；Flatten 反向把对应梯度还原到原 shape，不会阻止前层学习。整个模型只需要最终标签，不必给中间特征单独标注。

```python
from torch import nn

model = nn.Sequential(
    nn.Conv2d(3, 4, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(kernel_size=2, stride=2),
    nn.Flatten(start_dim=1),
    nn.Linear(64, 3),
)
```

输入 (8,3,8,8)，输出 (8,3)。若使用全局平均池化，把最后两步替换为：

```python
nn.AdaptiveAvgPool2d((1, 1)),
nn.Flatten(start_dim=1),
nn.Linear(4, 3),
```

这里指定每个通道汇总为 1×1。前面的特征从 (8,4,4,4) 改成 (8,4,5,5)，这条路线仍给 Linear 四个数；Flatten 路线则产生 100 个数，不能直接接原来的 Linear(64,3)。

## 小结与自检

池化汇总局部响应，步幅改变位置间隔，感受野记录跨层依赖范围；CNN 最后再把特征转成类别分数。

1. 最大池化没有参数，梯度会停止吗？**答：不会，最大值唯一时传给被选中的输入位置。**
2. 下采样后位置间隔变大，直接因为池化吗？**答：直接因为 stride；卷积也能产生同样间隔变化。**
3. 全局平均池化等于 Flatten 吗？**答：不等于，前者汇总空间值，后者保留各元素。**
4. 4×5×5 特征展开后能接 Linear(64,3) 吗？**答：不能，有 100 个输入特征，维度不匹配。**
