[上一节]({{< relref "/posts/generalization-and-regularization" >}})讲了 L2：在数据损失之外加入权重代价。这一节问：**把 L2 加进损失，与直接缩小权重，是同一回事吗？** 答案取决于更新规则。

## 1. 普通 SGD 中，两种写法可以相同

对一个权重 w，加 L2 后：

```text
总目标 = 数据损失 + λ/2 × w²
总梯度 = 数据梯度 g + λw
```

使用不带动量的普通 SGD：

```text
w新 = w − η(g+λw)
    = (1−ηλ)w − ηg
```

一次更新可以拆成：先按比例缩小原权重，再减去数据梯度的调整。这里的比例缩小就是 **weight decay，权重衰减**。

例如 w=2、g=3、η=0.1、λ=0.2：

```text
w新 = 0.98×2 − 0.1×3 = 1.66
```

若 g=0，则变成 1.96，即使没有数据梯度贡献，仍会缩小权重。

**这个等价关系来自不带动量的 SGD 公式与当前系数约定**，不能直接搬到 Adam。

## 2. Adam 加 L2：正则贡献也进入历史状态

把 L2 加进损失后，Adam 收到的混合梯度是：

```text
qₜ = gₜ + λwₜ₋₁
mₜ = β₁mₜ₋₁ + (1−β₁)qₜ
vₜ = β₂vₜ₋₁ + (1−β₂)qₜ²
```

接着做偏差修正，再用 `m̂/(√v̂+ε)` 更新参数：

```text
数据梯度 g ──┐
             ├→ q → m、v → 修正与缩放 → 更新
正则梯度 λw ─┘
```

λw 不只是被乘上学习率：它参与历史平均，也参与分母的平方尺度。因此，不能像普通 SGD 那样，把结果拆成同系数的直接衰减与数据更新。

### 手算：为什么不是缩小到 1.96？

取 w=2、数据梯度 g=0、λ=0.2、η=0.1，m、v 从零开始。Adam 收到 q=0.4。

以 β₁=β₂=0.9 为例：

```text
原始状态：m₁=0.1×0.4=0.04，v₁=0.1×0.4²=0.016
偏差修正：m̂₁=0.04/0.1=0.4，v̂₁=0.016/0.1=0.16
```

这里要注意帽子：**m₁ 是 0.04，修正后的 m̂₁ 才是 0.4**，不是原始状态直接等于梯度。

忽略很小的 ε：

```text
w新 ≈ 2 − 0.1×0.4/√0.16 = 1.9
```

同样 η、λ，直接衰减得到 1.96，Adam 加 L2 却约为 1.9。尺度缩放改变了正则贡献的作用。

## 3. AdamW：让权重衰减走单独的分支

AdamW 的 m、v 根据数据梯度 g 更新，不把 λw 混进去：

```text
数据梯度 g → 更新 m、v → 修正、缩放 → Adam 调整
当前权重 w → 直接计算 −ηλw          → 权重衰减
```

组合起来：

```text
w新 = (1−ηλ)w − η × m̂/(√v̂+ε)
```

这就是**解耦权重衰减**：保留 Adam 的自适应更新，但衰减不再经过历史平均和自适应分母。

仍用 w=2、g=0、λ=0.2、η=0.1，且历史状态为零，Adam 分支为零，结果为 1.96。

若从零状态开始，把数据梯度改成 g=3：

```text
m̂₁=3，v̂₁=9
Adam 调整 ≈ −0.1×3/3 = −0.1
衰减调整 = −0.1×0.2×2 = −0.04
w新 ≈ 2−0.1−0.04 = 1.86
```

更新状态用的是 3，不是 3.4。两项都对应更新前的权重和数据梯度，不能先把 Adam 更新后的 1.9 再乘 0.98，那会得到不同的 1.862。λ=0 时，这一步则退回不带衰减的 Adam，得到约 1.9。

## 4. 解耦不等于与学习率无关

在我们的约定下，直接衰减量是 `−ηλw`。同样 w=2、λ=0.2：

| 学习率 | 衰减调整 | 只做衰减后的权重 |
| --- | ---: | ---: |
| 0.1 | −0.04 | 1.96 |
| 0.05 | −0.02 | 1.98 |

所以固定 weight decay 系数，单次缩小比例也会随学习率变化。Warmup 初期学习率较小，同权重、同 λ 下的衰减幅度也较小。

**解耦的是衰减与 Adam 状态的处理路径，不是衰减与 η 的数值关系。**

## 5. 代码中不要无意叠加两种机制

```python
optimizer = torch.optim.AdamW(
    [w, b], lr=0.001, weight_decay=0.2,
)

optimizer.zero_grad(set_to_none=True)
pred = w * 50.0 + b
loss = (pred - 150.0) ** 2  # 数据损失
loss.backward()
optimizer.step()
```

weight_decay 对应上面的 λ，数值只作演示。想使用解耦衰减，损失里保留数据项即可。

如果又写 `loss=data_loss+λ/2×(w²+b²)`，L2 梯度会进入 m、v，优化器还会额外执行解耦衰减。这就同时使用了两种机制，不再是上述设置。

还可以通过参数组明确范围，例如对 w 衰减、对偏置 b 不衰减：

```python
optimizer = torch.optim.AdamW(
    [
        {"params": [w], "weight_decay": 0.2},
        {"params": [b], "weight_decay": 0.0},
    ],
    lr=0.001,
)
```

**b 不衰减不等于 b 不训练。** 它仍求数据梯度、维护自己的 m、v、执行 Adam 更新。是否排除某类参数，是模型与实验配置的选择，不是偏置绝对不能衰减的数学规定。

实现约定可核对 [PyTorch AdamW 文档](https://docs.pytorch.org/docs/2.15/generated/torch.optim.AdamW.html)。

## 6. 零梯度、历史状态与 None，要分开看

前面“g=0，只剩衰减”的例子，有一个重要条件：历史状态也是零。**当前没有新贡献，不代表过去的贡献消失。**

回顾偏差修正关系：

```text
m̂ₜ = mₜ/(1−β₁ᵗ)
v̂ₜ = vₜ/(1−β₂ᵗ)
```

m、v 是保存的状态，带帽子的是本步修正后用于更新的量。t 增大时，分母趋近 1，两者越来越接近。

取 β₁=β₂=0.9，第一步数据梯度为 2，第二步为 0：

```text
第一步：m₁=0.2，v₁=0.4
第二步：m₂=0.9×0.2=0.18，v₂=0.9×0.4=0.36

m̂₂=0.18/0.19≈0.9474
v̂₂=0.36/0.19≈1.8947
```

η=0.1 时，忽略 ε，第二步 Adam 分支仍带来约 −0.0688 的调整，再另外叠加 `−ηλw`。历史状态只是衰减，没有马上消失。

相反，零状态配合零梯度，m、v 更新后仍为零，修正后也为零，Adam 分支就是 `0/(0+ε)=0`。这是一种保证只剩衰减的情况，并非必须第一次更新；历史 m 恰好为零等情况下，也可能没有 Adam 调整。

最后区分 PyTorch 的两种梯度状态：

| 情况 | AdamW 本次怎样处理 |
| --- | --- |
| .grad 是零张量 | 仍处理参数，包括历史状态与权重衰减 |
| .grad is None | 跳过参数，本次连衰减也不执行 |

所以只清零 .grad，不能消除历史影响。zero_grad(set_to_none=True) 先清旧结果；随后没获得本轮梯度的参数会保持 None，不会自动变成零梯度。

## 小结与自检

Adam 加 L2 把两种梯度混在一起处理；AdamW 将数据驱动更新与直接衰减分开。判断结果时，还要检查历史状态和梯度是否存在。

1. AdamW 更新 m、v 时加入 λw 吗？**答：不加入，衰减走单独分支。**
2. weight_decay 固定，降低学习率影响直接衰减吗？**答：影响，同权重下衰减幅度随 η 缩小。**
3. 当前梯度为零，Adam 分支必为零吗？**答：不一定，历史 m 仍可能推动更新。**
4. .grad is None，设置了非零衰减就一定缩小参数吗？**答：不会，PyTorch AdamW 本次跳过该参数。**
