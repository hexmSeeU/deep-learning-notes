前面讲过 Linear 怎样组合输入。卷积也做加权求和，但加入两种结构约束：**每个输出先看局部输入，同一套权重在不同位置复用。** 本节只用单输入通道、单输出通道的小例子，不提前展开多通道、步幅或填充。

## 1. 先看一个窗口：对应相乘，再相加

把单通道图像写成数值矩阵，选一组 2×2 权重作为卷积核：

```text
输入：          卷积核：
1  2  3          1   0
4  5  6          0  −1
7  8  9
```

先让核覆盖左上角：

```text
局部输入：
1  2
4  5

输出 = 1×1 + 2×0 + 4×0 + 5×(−1)
     = −4
```

偏置暂设为 0。这个输出只使用局部四个数，没有连接整张图的九个输入。

再向右移动一格，覆盖 [[2,3],[5,6]]，结果是 2−6=−4。**权重没有换，只是乘到的输入换了。**

## 2. 滑动与共享：多个输出不是多套参数

这里每次移动一格，不在边缘补值，只在核能完整放下的位置计算：

| 位置 | 局部输入 | 输出 |
| --- | --- | ---: |
| 左上 | [[1,2],[4,5]] | −4 |
| 右上 | [[2,3],[5,6]] | −4 |
| 左下 | [[4,5],[7,8]] | −4 |
| 右下 | [[5,6],[8,9]] | −4 |

按位置排列，得到输出特征图：

```text
−4  −4
−4  −4
```

四个值相同，只是这张输入恰好各窗口有相同的对角差值，不是卷积要求各位置输出相同。

每个位置都使用同一组四个权重，这叫**权重共享**。含一个共享偏置，独立参数只有 2×2+1=5 个。输入变大、滑动位置增多，计算次数增加，但通道和核大小不变时，参数量不随位置增加。

### 偏置也在位置间共享

若 b=2，上面每个 −4 都变成 −2。不是四个输出各有独立偏置，而是这张输出特征图共用一个。

更一般地：

```text
加权结果：       加上 b=2：
 7  −7           9  −5
 0   3           2   5
```

偏置从 2 改为 5，各输出增加 3，位置之间的差值不变。

## 3. 同一个核，在各处问同一个局部问题

我们的核算的是“左上输入−右下输入”：

| 局部区域 | 响应 |
| --- | ---: |
| [[8,2],[3,1]] | 7 |
| [[1,2],[3,8]] | −7 |
| [[5,5],[5,5]] | 0 |

滑动是在不同位置使用同一种观察方式。特征图保留了回答的空间排列：哪里产生什么响应，仍有对应关系。

核是手选的，只为理解。训练时通常由数据与最终目标调整权重，不必提前给每个核指定含义。响应为零也不说明局部没有信息，只说明它对这个核的加权结果为零；不同局部区域可以得到同一个响应。

## 4. 和 Linear 比，限制在哪里？

同样 3×3 输入、输出四个数：

| 方式 | 每个输出连接 | 权重关系 | 含偏置参数量 |
| --- | --- | --- | ---: |
| Linear(9,4) | 全部九个输入 | 四个单元各一套 | 9×4+4=40 |
| 当前卷积 | 对应局部四个输入 | 各位置共用一个核 | 2×2+1=5 |

**局部连接与权重共享**适合利用图像的空间结构，是一种设计偏好，不是说 Linear 无法复现这些计算。给 Linear 设置特定零权重、重复权重，也能得到同样结果；只是普通 Linear 不自动保持这些约束。

如果四个位置各用独立的 2×2 权重，就不再是这里共享一个核、只有五个参数的层。

## 5. 先分清输出值与输出梯度

讨论反向时，最容易混淆的是两张矩阵：

```text
输出特征图 Y：      L 对各输出的导数：
y₁₁  y₁₂          ∂L/∂y₁₁  ∂L/∂y₁₂
y₂₁  y₂₂          ∂L/∂y₂₁  ∂L/∂y₂₂
```

左边是前向结果，右边是变化率。为说明来源，假设后续标量目标只是：

```text
L=y₁₁+y₁₂+y₂₁+y₂₂
```

那么各偏导数都是 1。任意一个输出单独增加 0.01，其他不变，L 就增加 0.01。

若改成 L=2y₁₁+y₁₂+y₂₁+y₂₂，输出梯度则为：

```text
2  1
1  1
```

这不是输出值变成了这些数字，而是目标对各输出的敏感程度不同。这里只用相加的目标演示求导，不代表真实训练一定如此；后续有激活、其他层和损失时，会传回相应导数。

## 6. 核权重的梯度：各位置贡献相加

把核记为：

```text
a  c
d  e
```

只看左上权重 a。左上输出为：

```text
y₁₁=a×1+c×2+d×4+e×5+b
```

所以 ∂y₁₁/∂a=1。若 ∂L/∂y₁₁=2，这条路径给 a 的贡献为 2×1=2。

使用刚才左上系数为 2 的目标，a 在各窗口分别乘到 1、2、4、5：

| 输出位置 | 上游导数 | a 乘的输入 | 对 a 的贡献 |
| --- | ---: | ---: | ---: |
| 左上 | 2 | 1 | 2 |
| 右上 | 1 | 2 | 2 |
| 左下 | 1 | 4 | 4 |
| 右下 | 1 | 5 | 5 |

```text
∂L/∂a=2+2+4+5=13
```

**同一个参数经过四条路径影响 L，因此汇总四份贡献，再更新这一个参数。** 不是每滑到一处就更新一份独立核。

若上游导数全为 1，总和是 12，共享偏置梯度为 4。若只有右上输出影响 L，即 L=y₁₂，a 的梯度就是 1×2=2。

一个 batch 有多张图时，还会继续汇总跨图的贡献；平均损失的缩放由上游计算传入，不在此处重复除一次。

## 7. 输入的梯度：重叠窗口也产生多条路径

看输入中心的 5，它被四个窗口覆盖，但在窗口中的相对位置不同。使用原核 [[1,0],[0,−1]]，令目标恢复为四个输出之和：

| 输出窗口 | 中心输入在窗口中的位置 | 对应核权重 | 上游为 1 时的贡献 |
| --- | --- | ---: | ---: |
| 左上 | 右下 | −1 | −1 |
| 右上 | 左下 | 0 | 0 |
| 左下 | 右上 | 0 | 0 |
| 右下 | 左上 | 1 | 1 |

传给中心输入的导数为 −1+0+0+1=0。**这个零是路径抵消，不是它没有参与前向。** 若只保留左上路径 L=y₁₁，导数则为 −1。

于是反向有两种汇总：同一核权重在多位置复用，汇总权重梯度；同一输入被多窗口覆盖，汇总输入梯度。

## 8. 卷积与激活仍然各有分工

卷积本身仍是加权求和、加偏置，不会自动产生非线性，输出可以为负。若后面接 ReLU：

```text
卷积结果：       ReLU 后：
 7  −7           7  0
 0   3           0  3
```

卷积负责共享的局部组合，激活逐元素引入非线性，不改变这张特征图的 shape。不能把 Linear 换成卷积，就认为不需要非线性。

## 小结与自检

本节的核心是：**局部计算、跨位置共享，以及反向中的路径贡献汇总。** 多通道、步幅与填充留到下一节。

1. 输入图变大，当前同一个核的参数量增加吗？**答：不增加，只增加使用位置与计算次数。**
2. 输出梯度矩阵全为 1，表示输出值全为 1 吗？**答：不是，表示最终目标对各输出的导数为 1。**
3. 目标只有右上输出，左上核权重 a 的梯度是多少？**答：2，因为它在该窗口乘到输入 2。**
4. 中心输入总梯度为 0，说明它没参与吗？**答：不一定，本例是多条路径贡献抵消。**
