[上一节]({{< relref "/posts/mini-batch-and-sgd" >}})讨论了每次用哪些样本求梯度。这一节继续问：**更新时，除了当前梯度，能不能参考之前几步的信息？**

## 1. 从当前梯度，到带历史的更新

不带动量的普通 SGD 使用 `参数 ← 参数 − 学习率×当前梯度`。假设学习率为 0.1，连续三步梯度为 `[2,−2,2]`，调整量就是 `[−0.2,+0.2,−0.2]`。

当前梯度一换方向，更新立即换方向，不会因为之前多次出现同向梯度而自动增强。梯度波动可能来自不同 mini-batch，也可能与函数形状和步长有关。

Momentum 增加一个跨步保存的状态。我们先采用**累积形式**：

```text
vₜ = βvₜ₋₁ + gₜ
θₜ = θₜ₋₁ − ηvₜ
```

其中 g 是当前梯度，v 是动量状态，η 是学习率，β 控制历史保留程度，通常 0≤β＜1。

取初始 v₀=0、β=0.9、η=0.1：

| 步骤 | 当前梯度 g | 新状态 v | 调整量 −ηv |
| --- | ---: | --- | ---: |
| 1 | 2 | 0.9×0+2=2 | −0.2 |
| 2 | −2 | 0.9×2−2=−0.2 | +0.02 |
| 3 | 2 | 0.9×(−0.2)+2=1.82 | −0.182 |

第二步历史贡献抵消了大部分反向梯度，参数只向反方向移动 0.02。如果第二步梯度是 −1，v 仍为 0.8，参数甚至会继续减小。

**当前梯度依然正常计算；改变的是更新使用的量，从 g 变成了 v。**

## 2. 同向会积累，历史会衰减

如果连续三步梯度都是 2，同样的设置下：

| 步骤 | v | 调整量 |
| --- | ---: | ---: |
| 1 | 2 | −0.2 |
| 2 | 3.8 | −0.38 |
| 3 | 5.42 | −0.542 |

展开第三步可以看到历史权重：

```text
v₃ = g₃ + βg₂ + β²g₁
```

**同向贡献叠加，反向贡献抵消，越早的梯度权重越小。** 即使第三步当前梯度为 0，前一步状态为 3.8，也仍有 `v=0.9×3.8=3.42`，参数会移动 −0.342。

β 越大，历史消退越慢。例如一份贡献经过 10 步，β=0.5 时只剩约 0.001，β=0.9 时仍剩约 0.35。β=0 则退回普通 SGD。

这能利用持续的方向，但也可能在需要转向时继续往前走。Momentum 不保证每步都更好，仍需要合适的学习率。

## 3. 动量不会把更新放大很多吗？

会。讨论中这个疑问很关键：**放大的是用于更新的状态 v，当前梯度 g 本身没有被改大。**

假设梯度始终固定为 2，β=0.9：

```text
vₜ = 0.9vₜ₋₁ + 2
```

若状态趋于稳定，则：

```text
v = 0.9v + 2
v = 20
```

一般来说，在恒定梯度的假设下：

```text
稳定的 v = g / (1−β)
```

所以这里 v 趋近于梯度的 10 倍，而非无限增长。若学习率为 0.1，长期调整量趋近于 −2，不再是普通 SGD 的 −0.2。

真实训练的梯度会随参数位置变化，也可能抵消，不能照搬恒定梯度的轨迹。但它说明：**β 不只影响平滑程度，也影响更新幅度，必须与学习率一起考虑。**

## 4. 累积形式与平均形式：差在哪里？

另一种常见写法是指数移动平均：

```text
累积形式：vₜ = βvₜ₋₁ + gₜ
平均形式：mₜ = βmₜ₋₁ + (1−β)gₜ
```

若 β 固定、两个状态都从 0 开始、使用相同梯度序列，则每一步都有：

```text
mₜ = (1−β)vₜ
```

平均形式给当前梯度多乘了 `(1−β)`。恒定梯度下，m 趋近于 g；累积形式的 v 则趋近于 `g/(1−β)`。

### 学习率怎样换算？

要让参数更新一致，需要：

```text
−η累积×vₜ = −η平均×mₜ

η累积 = η平均×(1−β)
```

以 β=0.9 为例：

| 写法 | 学习率 | 更新 |
| --- | ---: | --- |
| 平均形式 | 0.01 | −0.01mₜ |
| 累积形式 | 0.001 | −0.001vₜ |

因为 m=0.1v，上面两种调整量相同。反过来，若两者使用相同学习率，平均形式的调整量只有累积形式的 0.1 倍。

**这些数字用于公式换算，不是通用学习率推荐。** 阅读资料时，要把状态递推与参数更新公式一起看，不能只比较学习率数字。

## 5. 动量状态不是 .grad，也不是梯度累积

```text
当前 .grad 中的 gₜ ──────────┐
                            ├→ 新状态 vₜ → 更新参数
优化器保存的历史状态 vₜ₋₁ ──┘
```

| 概念 | 保存什么，何时更新 |
| --- | --- |
| `.grad` | 本轮求导结果，通常每轮清空 |
| 梯度累积 | 参数不变，多组梯度汇总后更新一次 |
| 动量状态 | 跨越多次参数更新，保留历史梯度贡献 |

`zero_grad()` 只清 `.grad`，不清优化器单独保存的动量。忘记清梯度也不能替代 Momentum：没有按 β 衰减，还混淆了本轮结果与历史状态。

## 6. 对应到 PyTorch

在其余相关选项保持默认时，`SGD` 的 momentum 对应我们讨论的累积形式：

```python
optimizer = torch.optim.SGD(
    [w, b], lr=0.001, momentum=0.9,
)
```

每个参数各有自己的动量状态，不把 w、b 的梯度混成一个数。第一步直接用当前梯度建立状态，与 v₀=0 的计算结果一致。

它没有直接切换成上述平均形式的开关。若目标是 β=0.9、学习率为 0.01 的平均形式，上面的 lr=0.001 就能在当前约定下得到相同参数更新；内部保存的仍是 v。实现约定可核对 [PyTorch SGD 文档](https://docs.pytorch.org/docs/2.14/generated/torch.optim.SGD.html)。

若要明确维护 m，也可以手写单参数更新：

```python
# 循环外初始化一次
m = torch.zeros_like(w)

# 每轮 backward 后执行
with torch.no_grad():
    m.mul_(0.9).add_(w.grad, alpha=0.1)
    w -= 0.01 * m
```

优化器同样要在循环外创建一次。每轮重新创建会丢失历史状态：即使参数值和当前梯度一样，新优化器的下一步也不保证与原优化器相同。

## 小结与自检

Momentum 的核心是：**更新既依赖当前梯度，也依赖历史状态。** 两种形式的尺度与学习率必须配套理解。

1. 当前梯度为 0，参数一定不动吗？**答：不一定，历史动量仍可使它移动。**
2. β=0.9、恒定梯度为 2，累积形式的 v 趋近多少？**答：20。**
3. β=0.9、平均形式学习率 0.01，对应累积形式学习率是多少？**答：0.001。**
4. 每轮 zero_grad 会丢失动量吗？**答：不会；每轮重新创建优化器才会失去原优化器的状态。**
