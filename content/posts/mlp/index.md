前两节分别讲了 [Linear]({{< relref "/posts/linear-output-units" >}}) 和[激活函数]({{< relref "/posts/activation-functions" >}})。现在把它们组合成一个 MLP，多层感知机：**前一层产生特征，后一层继续加工，最终目标通过反向传播影响各层参数。**

## 1. 隐藏层、宽度与深度

一个简单网络可以这样连接：

```text
输入 2 个特征 → Linear(2,3) → ReLU → Linear(3,1) → 1 个预测值
```

中间的三个数叫隐藏特征，对应三个隐藏单元。“隐藏”只表示网络内部结果，不是给定输入或最终输出。

第一层计算三种加权组合，经过 ReLU 后，第二层再组合这些隐藏特征。**第二层看到的是加工后的特征，不是直接使用原始输入。** 两个 Linear 各有自己的权重、偏置，可以一起训练。

若输入一个 batch，shape 为 (8,2)：

```text
(8,2) → (8,3) → (8,3) → (8,1)
           Linear    ReLU    Linear
```

改变隐藏单元数，就必须同时调整相邻层。例如隐藏层改为 5，网络应是 Linear(2,5) → ReLU → Linear(5,1)。

| 结构，数字为各层特征数 | 改变了什么 |
| --- | --- |
| 2→3→1 | 一个隐藏层，宽度 3 |
| 2→5→1 | 变宽，同一层计算更多特征 |
| 2→3→3→1 | 变深，增加一轮顺序加工 |

2→5→4→1 有两个隐藏层，宽度分别为 5、4。不同资料对层数的口径不一，这里明确区分隐藏层数和 Linear 层数。更宽、更深会改变参数量和表达能力，不保证结果一定更好。

## 2. 手算前向：隐藏特征怎样产生？

本篇用更小的网络：

```text
Linear(2,2) → ReLU → Linear(2,1)
```

输入 x=[1,2]。第一层权重与偏置使两个单元计算：

```text
z₁=x₁+x₂=3
z₂=x₁−2x₂=−3
```

经过 ReLU，再交给第二层：

```text
h=[ReLU(3),ReLU(−3)]=[3,0]
ŷ=2h₁−h₂+1=7
```

完整过程：

```text
[1,2] → [3,−3] → [3,0] → 7
          Linear    ReLU   Linear
```

若只把第二层偏置从 1 改成 0，预测变为 6，隐藏特征仍是 [3,0]。后面参数改变，不会倒过来改写前面这次计算。

隐藏特征也不需要单独的标签。训练用最终预测与答案计算损失，再沿计算图给内部各层提供更新依据。

## 3. 从最终目标，把梯度传回隐藏层

回到预测 ŷ=7，设最终标签 y=5：

```text
L=(ŷ−5)²=4
∂L/∂ŷ=2(7−5)=4
```

第二层为 ŷ=2h₁−h₂+1，因此：

```text
∂L/∂h₁=4×2=8
∂L/∂h₂=4×(−1)=−4
```

再经过 ReLU。由于 z₁=3 为正、z₂=−3 为负：

```text
∂L/∂z₁=8×1=8
∂L/∂z₂=(−4)×0=0
```

```text
最终损失 → 第二层 → 隐藏特征收到 [8,−4]
                         ↓ ReLU 的局部导数
                    第一层输出收到 [8,0]
```

所以，不需要先规定隐藏单元应该输出什么。**最终目标通过链式法则，把影响传到内部计算。** 第二个单元当前路径的梯度为零，不表示第一层所有参数为零，也不表示该单元对所有样本都失活。

## 4. 一次反向，前后两层都得到参数梯度

把第一层写为：

```text
z₁=w₁₁x₁+w₁₂x₂+b₁
z₂=w₂₁x₁+w₂₂x₂+b₂
```

当前 x=[1,2]，传到两个输出的导数为 8、0：

| 第一层参数 | 梯度 |
| --- | ---: |
| w₁₁ | 8×1=8 |
| w₁₂ | 8×2=16 |
| b₁ | 8 |
| w₂₁、w₂₂、b₂ | 都为 0 |

第二层写成 ŷ=a₁h₁+a₂h₂+c。当前 h=[3,0]、输出上游导数为 4：

```text
∂L/∂a₁=4×3=12
∂L/∂a₂=4×0=0
∂L/∂c=4
```

这里有两种不同的零梯度原因：

- a₂ 的梯度为零，因为它的输入 h₂ 为零。
- 第一层第二单元的梯度为零，因为 ReLU 的局部导数为零。

**a₂ 的梯度为零，不意味着传给 h₂ 的导数为零。** 后者是 4×a₂=−4，直到再经过 ReLU 才变成零。

更新时使用同一次前向对应的梯度，不能先更新第二层，再拿新权重向第一层传导。

## 5. 参数与中间结果不是一回事

| 组件 | 权重数量 | 偏置数量 | 合计 |
| --- | ---: | ---: | ---: |
| Linear(2,2) | 4 | 2 | 6 |
| ReLU | 0 | 0 | 0 |
| Linear(2,1) | 2 | 1 | 3 |
| 总计 | | | **9** |

z=[3,−3]、h=[3,0]、ŷ=7 是当前输入与参数产生的结果，不是额外的独立可学习参数。训练调整权重和偏置，下次重新前向才得到新的隐藏特征。

Batch 从 1 条增加到 100 条，只增加中间结果数量，网络仍有 9 个参数。若改成 Linear(2,3) → ReLU → Linear(3,1)，参数量则变为 (6+3)+(3+1)=13。

## 6. 用代码复现同一个网络

```python
import torch
from torch import nn

model = nn.Sequential(
    nn.Linear(2, 2),
    nn.ReLU(),
    nn.Linear(2, 1),
)

# 只为复现手算，手动设置相同参数
with torch.no_grad():
    model[0].weight.copy_(torch.tensor([
        [1.0,  1.0],
        [1.0, -2.0],
    ]))
    model[0].bias.zero_()
    model[2].weight.copy_(torch.tensor([[2.0, -1.0]]))
    model[2].bias.fill_(1.0)

x = torch.tensor([[1.0, 2.0]])
pred = model(x)
print(pred)        # tensor([[7.]], ...)
print(pred.shape)  # torch.Size([1, 1])
```

Sequential 按顺序传递结果；model[0]、model[2] 是两个 Linear，权重每行对应一个输出单元。正常训练通常从初始化参数开始，这里手动设置只为对齐例子。

一条样本的 shape 依次为 (1,2) → (1,2) → (1,2) → (1,1)。输入 8 条时，输出为 (8,1)。

接上训练：

```python
target = torch.tensor([[5.0]])  # 与 pred 对应，shape (1,1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.001)

optimizer.zero_grad(set_to_none=True)
pred = model(x)
loss = ((pred - target) ** 2).mean()
loss.backward()
optimizer.step()
```

model.parameters() 提供模型注册的可学习参数，包括两个 Linear 的权重、偏置；ReLU 没有参数。

**一次前向、一次 backward、一次 step，就能训练这些层。** 梯度为零不等于没交给优化器，只是本次普通 SGD 不改变它。

反过来，若只把 model[2].parameters() 交给优化器，反向仍可算第一层梯度，但这个优化器不会更新第一层。求导与参数管理是不同职责。

## 7. 隐藏层有激活，不代表输出层也必须加

本例最后一个 Linear 后没有 ReLU。如果再加，就会把预测限制为非负数。对可能为负的目标，例如温度变化量 −5，就无法表达正确答案。

隐藏层激活负责引入非线性，输出层处理则应与任务、损失定义配合，不能机械地给每个 Linear 都接同一种激活。分类怎样处理输出，下一节继续讨论。

## 小结与自检

MLP 把特征组合与非线性顺序连接起来；隐藏特征无需独立标签，最终损失会给各层提供梯度。

1. 网络 2→5→4→1 有几个隐藏层？**答：两个，宽度为 5、4。**
2. 第二层权重 a₂ 的梯度为零，传给它输入的导数也为零吗？**答：不一定，本例传给 h₂ 的是 −4。**
3. Batch 变大，独立参数量会变吗？**答：不会，中间结果变多，参数仍共享。**
4. 只将第二层参数传给优化器，它会更新第一层吗？**答：不会，即使第一层已经得到梯度。**
