看见一个张量，先回答两件事：**它的 shape 是什么？每个轴代表什么？** 本篇整理自第一节讨论，作为后续读代码时的速查。

## 1. 张量、轴与 shape

在深度学习中，可以先把张量理解为按一定形状排列的数。

| 例子 | 名称 | 轴的数量 | shape |
| --- | --- | --- | --- |
| `5` | 标量 | 0 | `()` |
| `[2, 4, 6]` | 向量 | 1 | `(3,)` |
| `[[1, 2, 3], [4, 5, 6]]` | 矩阵 | 2 | `(2, 3)` |

**轴（axis）表示一个索引方向，shape 记录各轴的长度。** 定位矩阵里的一个数需要行号和列号，因此有两个轴；并不是有六个数就叫六维张量。轴的编号从 0 开始。

`(3,)` 中的逗号是 Python 单元素元组的写法，不代表第二个轴。

## 2. shape 的数字没有自带语义

三套房子，每套记录面积、房间数两个特征：

```text
[[ 50, 2],
 [ 80, 3],
 [100, 4]]
```

shape 为 `(3, 2)`：第 0 轴是样本，第 1 轴是特征。一批一起计算的样本叫 **batch**，这里也可以写成 `(batch_size, 特征数)`。

同样的 `(3, 2)` 也可能是一张三行两列的灰度图片。**轴的含义来自数据约定，不来自 shape 本身。**

## 3. 图片：从二维数表到 NCHW

灰度图片的每个像素用一个数表示亮度；RGB 图片则用红、绿、蓝三个分量，也就是三个**通道（channel）**。

| 数据组织方式 | shape 示例 |
| --- | --- |
| 一张高 28、宽 28 的灰度图片，省略通道轴 | `(28, 28)` |
| 4 张这样的灰度图片，仍省略通道轴 | `(4, 28, 28)` |
| 4 张灰度图片，显式保留通道轴 | `(4, 1, 28, 28)` |
| 8 张高 64、宽 32 的 RGB 图片 | `(8, 3, 64, 32)` |

PyTorch 图像处理中常见的排列是 **`(N, C, H, W)`**：图片数量、通道数、高度、宽度。有些工具使用 `(H, W, C)` 表示单张图片，要先确认约定。

这里的“三维”“四维”说的是数据有几个轴，不是图片变成了立体图像。**长度为 1 的轴仍然存在。**

## 4. 整数索引去掉轴，切片保留轴

设 `x.shape = (8, 3, 64, 32)`：

| 操作 | 结果 shape | 含义 |
| --- | --- | --- |
| `x[0]` | `(3, 64, 32)` | 第 1 张图片 |
| `x[0:1]` | `(1, 3, 64, 32)` | 只有第 1 张图片的 batch |
| `x[0:2]` | `(2, 3, 64, 32)` | 前两张图片组成的 batch |
| `x[2, 0]` | `(64, 32)` | 第 3 张图片的第 1 个通道 |
| `x[0, 1, 10, 20]` | `()` | 一个像素分量，结果是 0 维张量 |

整数索引固定一个位置，就去掉对应轴。切片选择一段范围，**包含起点、不包含终点**，并保留对应轴。

`x[0]` 和 `x[0:1]` 选中同一张图片的数据，但后者保留了 batch 轴，不能忽略这个区别。

## 5. 三个容易混淆的量

仍以 `(8, 3, 64, 32)` 为例：

| PyTorch 写法 | 结果 | 表示什么 |
| --- | --- | --- |
| `x.ndim` | `4` | 轴的数量，也叫维数或 rank |
| `x.shape` | `torch.Size([8, 3, 64, 32])` | 每个轴的长度 |
| `x.numel()` | `49152` | 元素总数，即各轴长度的乘积 |

`(3, 64, 32)` 与 `(1, 3, 64, 32)` 的元素总数相同，轴的数量却不同。**数一样多，不代表组织方式一样。**

## 6. 文本：编号与 embedding

文本通常先被切成 **token**，再转成编号。token 可能是字、词或词的一部分，不直接等于一个字。编号只表示身份，数值更大不代表更重要。

若一个 batch 有 8 段文本，每段 20 个 token：

- **编号张量：`(8, 20)`，即 `(B, T)`**。B 是 batch size，T 是序列长度。
- **embedding 后：`(8, 20, 128)`，即 `(B, T, D)`**。每个编号被转换为一个长度为 128 的向量，D 是嵌入维度。

“嵌入维度是 128”说的是向量长度；整个张量仍只有 3 个轴。不同长度文本怎样组成 batch，留到后面讨论。

## 小结与自检

记住三条：**shape 看长度，轴的语义看约定，索引后重新确认 shape。**

1. `(2, 3, 4)` 有几个轴、多少元素？**答：3 个轴，24 个元素。**
2. `x.shape = (8, 3, 64, 32)`，取第 3 张图片并保留 batch 轴？**答：`x[2:3]`，shape 为 `(1, 3, 64, 32)`。**
3. 为什么 `(B, T, 128)` 不叫 128 维张量？**答：128 是最后一个轴的长度；按轴的数量说，它是 3 维张量。**
